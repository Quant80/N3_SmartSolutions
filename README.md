# N³ SmartSolutions — DAQS

AI-powered educational platform for South African Grade 8–12 learners (Mathematics & Physical Sciences).

## Features

- **Teacher Dashboard** — class management, assignment creation & lifecycle (lock/extend/archive/version), AI auto-marking, submissions review, Q-Bank, analytics reports
- **Student Interface** — AI chat tutor (Claude, DeepSeek, OpenAI, Qwen), NSC past papers browser, formula reference, photo solver, progress tracking, assignment submission
- **Admin Panel** — platform overview, user management
- **AI Providers** — Claude (Anthropic), DeepSeek, OpenAI GPT-4o, Qwen, OpenRouter
- **Math Rendering** — MathJax for LaTeX equations
- **Responsive** — mobile and desktop layouts

## Live App

[https://quant80.github.io/N3_SmartSolutions/](https://quant80.github.io/N3_SmartSolutions/)

## Getting Started (Local)

Open `index.html` in any modern browser — no build step required.

To use AI features, enter your API key in Settings inside the app (Claude, DeepSeek, OpenAI, or OpenRouter key).

## Deployment

This project deploys automatically to GitHub Pages on every push to `main` via GitHub Actions (`.github/workflows/deploy.yml`).

## Part of DAQS

N³ SmartSolutions is one of the N3 solutions within the DAQS (Digital Assessment & Query System) product family.
